# NewTqnia | Technology News, AI and Innovation

An independent bilingual (English/Arabic) technology newsroom covering AI, cybersecurity, developer tools, science, and global innovation. Provides a free public REST news API (Daily Digest), an OpenAPI 3.1 contract, a hosted MCP server, an llms.txt, and official SDKs.

## APIs

- **NewTqnia Daily Digest API** — Public read-only JSON REST API exposing today's and the latest published articles. No API key required for the initial release; optional headers for application/website attribution. Rate limited to 60 requests/minute per IP with ETag and Cache-Control support. (`https://api.newtqnia.com`)

> Confirmed live surfaces: REST API (base https://api.newtqnia.com with GET /v1/news/today and /v1/news/latest), OpenAPI 3.1 at https://newtqnia.com/openapi.yaml (v1.1.0, read-only), hosted MCP server at https://newtqnia.com/mcp (MCP/Streamable HTTP, tools: get_recent_news, get_news_by_id, get_timeline_by_id, search_terminology, search_explainers, server_status), and llms.txt at https://newtqnia.com/llms.txt (plus expanded index llms-full.txt). Auth is optional API key (ntq_ prefix) via X-API-Key; MCP requires personal key or OAuth. Official SDKs: Python (pip newtqnia), PHP (composer newtqnia/php), Node/TS (newtqnia-node), Go (newtqnia/newtqnia-go). No GraphQL, AsyncAPI, Postman collection, or published agent skills found. The apis.json at https://newtqnia.com/apis.json was not directly fetchable during research, but all referenced artifacts were independently confirmed live. Attribution ('Powered by NewTqnia' with a visible link) is required when displaying API content.
